# Contribuir a BoraLume

Gracias por ayudar a crear este espacio para ARMY. También puedes contribuir con pruebas de accesibilidad, traducciones, ideas y reportes de dispositivos.

1. Lee `docs/specs/001-foundation.md` y `docs/architecture.md`.
2. Instala Node >=22.13 y ejecuta `npm ci` y `npm run dev`.
3. Mantén el cambio enfocado. Reutiliza MUI, los tokens del tema y los componentes existentes.
4. Incluye una descripción de la necesidad, comportamiento resultante y validación. Para cambios visuales, adjunta capturas en claro/oscuro y móvil/escritorio.
5. Ejecuta `npm run check`; si cambias navegación, formularios, persistencia o PWA, ejecuta `npm run test:e2e` tras compilar.

No incluyas canciones, imágenes ni coreografías ajenas sin permiso. Documenta las licencias de cualquier dependencia o contenido nuevo. No incluyas capturas de audio, direcciones de dispositivos ni datos personales en reportes públicos. Aún no hay soporte físico de ARMY Bomb certificado.

La identidad de la fundadora y la política de créditos de secuencias se definirán con ella. Atribuimos las aportaciones de cada persona sin inventar afiliación oficial con BTS/HYBE.
